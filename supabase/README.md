# supabase/

Populated once a Supabase project exists and `supabase init` has been run
locally. Planned layout:

```
supabase/
  config.toml       # generated by `supabase init`
  migrations/        # plain SQL migrations, source of truth for schema
  functions/         # Edge Functions for server-enforced business rules
                      # (application status transitions, agreement
                      # acceptance recording, membership creation)
```

See `docs/DATA_MODEL.md` for the schema this will implement and
`docs/ACCESS_CONTROL.md` for the RLS/Edge Function split.
