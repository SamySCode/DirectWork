How deletion happens:

- **Rows**: `private.apply_retention()` runs nightly at 03:17 through
  `pg_cron` on the hosted project (migration
  `20261105120000_launch_hardening.sql`).
- **Files** (images, attachments): deleted through the Storage API by the
  `maintenance` Edge Function, which empties the `private.storage_cleanup`
  queue. It must be scheduled daily (`docs/NEXT_STEPS.md` step 2.15).
- **Account deletion**: the `delete-account` function cancels any Stripe
  subscription, deletes the user's files, then deletes the user, which
  removes their rows (except anonymised reports). Refused while a legal hold
  exists.
