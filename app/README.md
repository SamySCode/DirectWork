# app/

Expo Router file-based routes go here once Expo is scaffolded
(`npx create-expo-app`). Planned top-level groups:

- `(auth)/` — sign-in, sign-up, forgot-password
- `(onboarding)/` — profile setup, skills, paid/partner interest
- `(tabs)/` — dashboard, discover, applications, messages, profile
- `project/[projectId]/` — listing detail, manage, apply, workspace
- `agreement/[applicationId]/` — partner agreement acceptance flow
- `profile/[userId]/` — public profile view
- `settings/`

See `docs/ARCHITECTURE.md` for the full route map and rationale.
